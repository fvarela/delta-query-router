## Decisions

| Decision | Options | Chosen | Why |
|----------|---------|--------|-----|
| Python version pin | `.python-version` 3.12 + `requires-python = ">=3.12"`; or `==3.12.*` | `.python-version` = `3.12`, `requires-python = ">=3.12"` | DESIGN says 3.12; uv installs it; `>=` avoids a forced edit for a later upgrade |
| Build backend | `uv_build`, `hatchling`, none | `uv_build` | Native to uv, needed so `src/dqr` is importable as `dqr` |
| Project name | `dqr`, `delta-query-router` | `dqr` | Matches the module name; no extra build config |
| Dev tools | `[dependency-groups] dev` vs optional extras | `dev = ["pytest", "ruff"]` group | `uv sync` installs the `dev` group by default; images later install without it |
| Integration tests | skip via `addopts = -m "not integration"`; skip via conftest hook | `addopts` with `-m "not integration"` plus `--strict-markers`, marker registered in `[tool.pytest.ini_options]` | Plain config, visible in one place; `uv run pytest -m integration` runs them explicitly |
| Ruff rules | defaults only; `E,F,I,UP,B` | `select = ["E", "F", "I", "UP", "B"]`, `target-version = "py312"`, default line length 88 | Catches import order, old syntax and common bugs without noise |
| Smoke test | import test; none | `tests/test_smoke.py` imports `dqr` | Proves the package layout and build backend work |
| Old AGENTS.md environment notes (Docker Hub mirror, TLS check) | carry over now; add later | Add later, when Docker images are built and the notes are re-verified | They describe the v1 setup and an older network; unverified facts don't belong in AGENTS.md |
| Which section 9 directories to create now | A: only `src/dqr/` (just `__init__.py`, no subpackages) + `tests/`, everything else when first needed; B: all now with `.gitkeep` | A (author, 2026-11-01) | No placeholder files or empty packages; each directory appears with real content.
